# Install:  pip install -r requirements.txt
# ========================================================================
#
# WINDOWS / GPU (RTX 5090 / Blackwell) - IMPORTANT
# ------------------------------------------------------------------
# On Windows, `pip install torch` resolves to a CPU-ONLY wheel by default.
# To get the CUDA build, install torch/torchvision from the matching cu*
# index FIRST, then install the rest:
#
#     pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
#     pip install -r requirements.txt
#
#   (use cu126 / cu132 to match your installed CUDA + driver)
#
# Verify the GPU is actually usable:
#     python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_capability(0))"
#   -> expected:  True  (12, 0)   on RTX 5090 (sm_120 = Blackwell)
#
# torch >= 2.7 is the first line with Blackwell (sm_120) support, so do not
# pin it below that for a 50-series GPU.
#
# CUDA_HOME (and CUDA toolkit / nvcc) is NOT required by our stack: we install
# GroundingDINO from the pure-Python `rf-groundingdino` PyPI wheel (no
# compile step). You would only need CUDA_HOME for the slow git+IDEA-Research
# variant or packages that compile their own CUDA kernels at install time
# (flash-attn, xformers, bitsandbytes, triton). If you add such a package
# below, note it as a comment on that line.
# ========================================================================

# ── Ollama VLM: the --tracker ollama mode AND the advisory --vlm ───
# The `ollama` Python client talks to a running `ollama serve` process.
# It is only needed if you use `--tracker ollama` (LLM generation of
# funscript) or the advisory `--vlm` flag.  The tracker registry's
# create_tracker("ollama", ...) still works without it (the client is

# call if you forgot the `pip install`.
#
# Pillow ships as a dependency of `ollama` (used by
# core/postpass/llm_gen._thumb_b64 for the image thumbnails).  Do not
# forget that a running Ollama server (with at least one multimodal /
# vision model pulled) is required for tracker=ollama to work.
